# Come usare la libreria di conversione decimale e binaria scritta in C 

1. Aprire il terminale e scrivere i seguenti comandi 

2. cd 9.decimal_binary_converter_library/

3. make run 

dopo questi 3 semplici passaggi il programma e pronto all uso vi chiedera di scrivere un numero decimale o binario e lo convertira alla velocita della luce.
